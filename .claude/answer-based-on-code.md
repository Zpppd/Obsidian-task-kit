回答用户关于项目功能状态的问题时，必须以**实际代码**为唯一真相来源。

**Why:** 文档（路线图、规格说明）中的 ✅ 状态标记可能与实际代码不同步；用户的口头说法（"还没开始做"）也可能基于过时记忆。只有代码是真实状态。

**How to apply:**
1. 当被问到"某某功能做了没"或评估项目状态时，先读相关代码文件，再看文档
2. 如果用户说法与代码不符，用代码证据礼貌纠正，而不是顺着用户说
3. 如果文档与代码不符，以代码为准，同时指出文档需要更新
