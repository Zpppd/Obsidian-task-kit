# Task Master Pro

Obsidian 插件，提供任务面板、时间追踪和提醒通知功能。

## 功能

**任务面板**
在 Obsidian 右侧边栏中展示所有 Markdown 文件中的任务，支持按状态筛选和搜索，点击任务跳转到对应行。

**三态流转与时间追踪**
`[ ]` → `[/]` → `[x]` 三态切换，点击 checkbox 自动记录起止时间，支持自定义时间标记格式。
可单独关闭时间追踪，关闭后恢复 Obsidian 原生的 `[ ]` ↔ `[x]` 切换行为。
支持对进行中任务 `[/]` 的提醒（需在设置中开启）。

**提醒通知**
在任务行末尾添加 `(@时间)` 设置提醒，到期自动弹窗。
支持三种输入方式：
- `(@2026-05-21 14:05)` 完整日期+时间
- `(@14:00)` 仅时间，默认为今天
- `(@2026-05-21)` 仅日期，自动加上默认提醒时间
支持 Obsidian 内置弹窗和 Windows 系统通知（可同时开启），弹窗内可标记完成、稍后提醒（时间预设可配置）、静音、打开文件。

## 使用

### 创建任务

在 Markdown 文件中写标准 Obsidian 任务格式：

```
- [ ] 买咖啡 (@14:00)
- [ ] 写报告 (@2026-05-21 14:00)
- [ ] 回顾 (@2026-05-21)
```

### 打开面板

点击左侧 Ribbon 栏的列表图标，或在命令面板中执行 Open Task Panel（默认无快捷键）。

### 时间追踪

点击任务的 checkbox 触发三态流转：

```
- [ ] 待办 → 点击 → - [/] 进行中 (:14:30) → 点击 → - [x] 已完成 (:14:30 - 15:45)
```

时间标记格式可在设置中自定义，可用变量：

| 变量 | 说明 | 示例 |
|------|------|------|
| {start} | 开始时间 | 14:30 |
| {end} | 结束时间 | 15:45 |
| {startDate} | 开始日期时间 | 2026-05-21 14:30 |
| {endDate} | 结束日期时间 | 2026-05-21 15:45 |
| {duration} | 耗时分钟数 | 75 |
| {durationDate} | 耗时文本 | 1小时15分钟 |

### 提醒

到时间后自动弹出提醒窗口，支持四个操作：
- 标记完成：将任务标为 `[x]`
- 稍后提醒：从预设时间中选择（可在设置中自定义）
- 今日静音：当天不再弹此任务
- 打开文件：跳转到任务所在位置

## 安装

1. 从 Releases 下载最新版
2. 解压到 `vault/.obsidian/plugins/task-master-pro/`
3. 在 Obsidian 设置中启用插件

## 设置

在设置 → Task Master Pro 中可配置：

- 时间追踪开关、时间标记格式
- 提醒开关、默认提醒时间、稍后提醒预设
- 内置弹窗和系统通知开关
- 扫描目录白名单

## 开发

```bash
npm install
npm run build
```
