# TaskPanelView 快速测试指南

## 🚀 快速开始

### 1. 构建插件

```bash
cd "e:\code-Project\task-reminders-tracking\task-master-pro"
npm run build
```

### 2. 在 Obsidian 中启用插件

1. 打开 Obsidian
2. 进入 **设置** → **社区插件**
3. 点击 **已安装插件** 旁边的刷新按钮
4. 找到 **Task Master Pro** 并启用

### 3. 打开任务面板

**方法 1：命令面板**
- 按下 `Ctrl + P` (Windows) 或 `Cmd + P` (Mac)
- 输入 "Open Task Panel"
- 选择该命令

**方法 2：快捷键（可选配置）**
- 在设置中为 "Open Task Panel" 配置快捷键

## 🐛 常见问题排查

### 问题 1：面板打不开
**症状**：执行命令后无任何反应  
**排查**：
1. 检查控制台是否有错误信息
2. 确认插件已成功加载（查看控制台日志 "Task Master Pro loaded!"）
3. 确认 test-tasks.md 文件存在且包含任务

### 问题 2：任务列表为空
**症状**：面板打开但显示"暂无任务"  
**排查**：
1. 确认 vault 中有 Markdown 文件
2. 确认文件中包含 `- [ ]`、`- [x]` 或 `- [/]` 格式的任务
3. 查看控制台是否有解析错误

### 问题 3：点击任务不跳转
**症状**：点击任务项后没有反应  
**排查**：
1. 确认任务有有效的 filePath
2. 确认文件存在于 vault 中
3. 查看控制台是否有错误信息

### 问题 4：状态切换失败
**症状**：点击 checkbox 后状态不变或报错  
**排查**：
1. 确认 TimeTrackerService 已正确初始化
2. 确认任务文件格式符合预期
3. 查看控制台详细错误信息

### 问题 5：面板不自动刷新
**症状**：修改文件后面板内容不更新  
**排查**：
1. 确认文件监听器已注册（查看 onOpen 中的 registerEvent 调用）
2. 等待至少 500ms（防抖时间）
3. 尝试手动重新打开面板
